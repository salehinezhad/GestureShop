# GestureShop — نسخهٔ اصلاح‌شدهٔ کنترل یک‌دستی (V2)

**این همان پروژهٔ قبلی React / TypeScript / Vite است، نه یک پروژهٔ تازه.** فایل‌های فروشگاه، تصاویر واقعی ۶ محصول، مسیریابی، سبد خرید، MediaPipe و مدل محلی تشخیص دست حفظ شده‌اند. تغییرات روی موتور ژست‌های موجود و صفحهٔ جزئیات اعمال شده است.

## راه‌اندازی

پیشنهاد: Node.js 24.15+ (بعضی وابستگی‌های قفل‌شده با Node 22 قدیمی سازگار نیستند).

```bash
npm ci
npm run dev
```

سایت را روی `http://localhost:5173` یا نشانی اعلام‌شده در ترمینال باز کنید. به وب‌کم اجازه بدهید و نور رو‌به‌رو را تنظیم کنید. برای استفاده از وب‌کم روی گوشی باید سایت با HTTPS باز شود (یا localhost همان دستگاه). برای بررسی:

```bash
npm run check
npm run build
```

پوشه‌های `node_modules` و `dist` عمداً داخل ZIP نیستند. تصاویر، مدل `public/models/hand_landmarker.task` و فایل‌های MediaPipe WASM **داخل ZIP موجودند** و به دانلود جداگانه نیاز ندارند.

## ژست‌های نسخهٔ جدید — با یک دست

| حالت دست / حرکت | عملکرد |
| --- | --- |
| ✋ کف دست باز و ثابت حدود ۰٫۲۳ ثانیه | فعال شدن کنترل حرکتی |
| ↔️ حرکت کف دست باز به چپ/راست **یا** کج‌کردن مچ تا نوک انگشت‌ها به چپ/راست اشاره کند | روی خانه: تغییر **خود محصول**. روی صفحهٔ جزئیات: تغییر تصویر گالری |
| 👇 کشیدن مچ با کف دست باز به سمت پایین | ورود به صفحهٔ اختصاصی جزئیات محصول |
| 👌 علامت OK (شست+اشاره حلقه شوند، سایر انگشت‌ها باز) | افزودن **یک** محصول به سبد + افزایش شمارنده |
| ✌️ دو انگشت V (اشاره و وسط باز، حلقه و کوچک جمع) | **باز شدن فوری سبد خرید**، بدون نیاز به نشانه‌گیری روی آیکن |
| ✊ سپس ✋ مشت و بازکردن دست | بستن سبد/پنجرهٔ راهنما یا برگشت از جزئیات |

**نکتهٔ کاربردی:** برای تعویض چندباره، پس از هر چرخاندن مچ آن را حدود ۰٫۱۵ تا ۰٫۲ ثانیه به وضعیت وسط برگردانید یا لحظه‌ای ثابت نگه دارید و بعد دوباره حرکت کنید. نگه داشتن دست در انتهای حرکت نباید چند محصول را پشت‌سر‌هم عوض کند.

برای باز کردن سبد، کافی است دو انگشت اشاره و وسط را به شکل ✌️ نگه دارید؛ لازم نیست نشانگر را روی آیکن سبد ببرید. این ژست حدود ۰٫۱۶۵ ثانیه مکث دارد تا سریع عمل کند ولی با فریم‌های گذرا اشتباه نشود. ژست OK مستقل است و همچنان مثل قبل با هر اجرا فقط یک محصول اضافه می‌کند. **زوم و کنترل دو‌دستی وجود ندارد.**

## تفاوت صفحهٔ جزئیات

صفحهٔ دوم با **بنر بزرگ سبز تیرهٔ «یک نگاه نزدیک‌تر» و نشانۀ 02 / PRODUCT DETAILS** از صفحهٔ اصلی کاملاً متمایز شده است. صفحهٔ جزئیات شامل گالری سه‌عکسی، اطلاعات و مشخصات متمرکز و کادر خرید سبز تیره است؛ برای ضبط عمودی ریلز نیز استایل واکنش‌گرا دارد. صفحهٔ اصلی همان تم کرم/سبز مورد تأیید را حفظ می‌کند.

## تست سریع روی لپ‌تاپ

1. دوربین را روشن و کف دست باز را کمی نگه دارید تا «کنترل فعال» شود.
2. پنج انگشت را باز نگه دارید و **مچ دست راست را به یک سمت کج کنید**؛ یک محصول عوض می‌شود. مچ را به وسط برگردانید و دوباره به همان سمت ببرید تا محصول بعدی بیاید.
3. دست باز را از بالا به پایین ببرید؛ وارد صفحهٔ جزئیات با بنر سبز شوید.
4. 👌 بسازید؛ شمارندهٔ سبد افزایش پیدا کند.
5. ✌️ بسازید؛ سبد باز شود.
6. مشت کنید و سپس باز کنید؛ سبد بسته شود.

اگر تشخیص کند بود یا زاویهٔ دوربین با دست شما متفاوت است، عددهای `src/gesture/config.ts` مثل `tiltThreshold`، `swipeMinDisplacement` و `vHoldMs` قابل تغییرند؛ اما بهتر است ابتدا با نور کافی و فاصلهٔ حدود نیم متر تست کنید. سمت چپ/راست برای **تصویر آینه‌ای پیش‌نمایش وب‌کم** تنظیم شده است.

## تغییرات فنی

- حفظ ساختار فایل‌ها، مسیریابی، فروشگاه، سبد خرید، دوربین و سایر ماژول‌های کارآمد.
- افزودن تشخیص pose `VICTORY` برای دو انگشت با action مستقیم `open-cart`؛ حذف نیاز قبلی به نشانه‌گیری دقیق روی آیکن و مکث ۱ ثانیه‌ای.
- افزایش انعطاف تشخیص کف دست در جهت‌های مایل، افزودن شناسایی زاویهٔ مچ **و** حرکت افقی مچ؛ کاهش منطقی آستانه‌ها و تأخیر، با قفل هر حرکت تا بازگشت به حالت عادی.
- حفظ ژست OK با محافظ ضد افزودن چندباره؛ حفظ حرکت پایین و مشت/باز کردن دست.
- بازنویسی متن راهنمای فارسی براساس ژست‌های واقعی.
- بازطراحی هدفمند صفحهٔ جزئیات: بنر مستقل، خوانایی و کنتراست بیشتر، مناسب نمایش تفاوت دو صفحه در ریلز.
- هیچ ژست pinch/zoom و هیچ وابستگی 3D تازه‌ای اضافه نشده است.

## وضعیت آزمایش و محدودیت صادقانه

منطق تشخیص دست با مجموعه‌ای از فریم‌های مصنوعی landmark در محیط آفلاین بررسی شده: حالت کف دست، OK، V، حرکت افقی، کج کردن مچ و حرکت به پایین. همچنین تحلیل Syntax فایل‌های TS/TSX بدون خطای نگارشی انجام شد. **تست فیزیکی با وب‌کم واقعی انجام نشده** و **اجرای کامل `npm run build` و Vitest در این محیط ممکن نشد**، چون دریافت بسته‌های npm به‌دلیل محدودیت شبکه شکست خورد. بعد از `npm ci` روی لپ‌تاپ، `npm run check` و `npm run build` را اجرا کنید و حرکات را در نور واقعی بررسی کنید. آستانه‌ها ممکن است با زاویهٔ دست و مدل دوربین شما نیاز به تنظیم داشته باشند.

این یک نمونه‌نمایشی فروشگاه است؛ قیمت‌ها آزمایشی‌اند و پرداخت آنلاین واقعی انجام نمی‌شود.


## نسخه V3 — جهت پنج انگشت و صفحه جزئیات بدون اسکرول
- کف دست باز رو به بالا: فعال‌سازی.
- پنج انگشت باز به چپ: محصول قبلی؛ به راست: محصول بعدی. نیازی به جابه‌جایی دست نیست.
- پنج انگشت باز رو به پایین: ورود به جزئیات همان محصول.
- OK: افزودن به سبد؛ ✌️: بازکردن سبد؛ مشت و سپس کف باز: بازگشت.
- تشخیص جهت با میانگین چهار نوک انگشت نسبت به مفاصل پایه انگشت‌ها انجام می‌شود؛ تغییر جهت مستقیم چپ↔راست پشتیبانی می‌شود.
- در صفحه جزئیات، تصویر بزرگ، قیمت و دکمه خرید در ابتدای صفحه‌اند؛ در موبایل مشخصات تکمیلی برای جلوگیری از اسکرول مخفی شده‌اند.
- حساسیت ردیابی افزایش یافته، اما فاصله مؤثر همچنان به کیفیت وب‌کم، نور و اندازه دست در تصویر بستگی دارد.
- برای نصب بسته‌ها `npm ci` و سپس `npm run dev`؛ برای بررسی `npm run check` و `npm run build`.
