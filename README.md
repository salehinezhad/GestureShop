## 🚀 معرفی پروژه

**GestureShop** یک پروژه فروشگاه اینترنتی مدرن با رابط کاربری فارسی است
که امکان کنترل بخش‌هایی از فروشگاه را با استفاده از حرکات دست فراهم می‌کند.

این پروژه با هدف ترکیب برنامه‌نویسی وب، هوش مصنوعی
و فناوری تشخیص حرکات دست توسعه داده شده است.

کاربر می‌تواند با قرار دادن دست مقابل وب‌کم،
بدون نیاز به لمس موس یا کیبورد، با فروشگاه تعامل داشته باشد.

### ✨ ویژگی اصلی پروژه

کنترل فروشگاه تنها با یک دست!

برای انجام عملیات مختلف، از حرکات مشخص دست استفاده می‌شود.

# ✋ راهنمای کامل کنترل با حرکت دست

GestureShop از شش حرکت اصلی برای تعامل با فروشگاه استفاده می‌کند.

## 1️⃣ کف دست باز ✋

### فعال‌سازی کنترل حرکتی

کف دست خود را مقابل وب‌کم قرار دهید.

پس از شناسایی دست، سیستم کنترل حرکتی فعال می‌شود.

**عملکرد:**

- تشخیص دست توسط وب‌کم
- فعال‌سازی کنترل حرکتی
- آماده‌سازی سیستم برای دریافت حرکات

---

## 2️⃣ حرکت مشت به چپ و راست ✊ ↔️

### تغییر تصاویر محصول

دست خود را مشت کنید و آن را به سمت چپ یا راست حرکت دهید.

با هر حرکت معتبر، تصویر فعلی محصول تغییر می‌کند.

**عملکرد:**

- حرکت به راست: نمایش تصویر بعدی یا قبلی طبق جهت تنظیم‌شده
- حرکت به چپ: جابه‌جایی در جهت مخالف
- نمایش زوایای مختلف همان محصول

**نکته:** این حرکت تصاویر یک محصول را تغییر می‌دهد،
نه اینکه محصول دیگری انتخاب کند.

---

## 3️⃣ حرکت دست به پایین 👇

### ورود به صفحه جزئیات محصول

با حرکت دست به سمت پایین،
صفحه جزئیات محصول انتخاب‌شده باز می‌شود.

**عملکرد:**

- ورود به صفحه محصول
- مشاهده اطلاعات بیشتر
- مشاهده مشخصات و تصاویر محصول

---

## 4️⃣ علامت OK 👌

### افزودن محصول به سبد خرید

انگشت شست و اشاره را به شکل علامت OK قرار دهید.

با تشخیص این حرکت، محصول انتخاب‌شده
به سبد خرید اضافه می‌شود.

**عملکرد:**

- افزودن محصول به سبد خرید
- افزایش تعداد محصولات سبد
- نمایش بازخورد ثبت موفق

---

## 5️⃣ علامت دو انگشت ✌️

### باز کردن سبد خرید

دو انگشت اشاره و وسط را بالا نگه دارید.

سیستم این علامت را تشخیص می‌دهد و
پنجره سبد خرید را باز می‌کند.

**عملکرد:**

- باز کردن سبد خرید
- نمایش محصولات انتخاب‌شده
- مشاهده تعداد و قیمت محصولات

---

## 6️⃣ مشت و سپس باز کردن دست ✊✋

### بستن سبد خرید

ابتدا دست خود را مشت کنید و سپس آن را باز کنید.

با شناسایی این حرکت، پنجره سبد خرید بسته می‌شود.

**عملکرد:**

- بستن پنجره سبد خرید
- بازگشت به محیط فروشگاه

# 💻 نصب و اجرای پروژه

## پیش‌نیازها

برای اجرای پروژه به موارد زیر نیاز دارید:

- Node.js
- npm
- مرورگر مدرن
- وب‌کم برای استفاده از کنترل حرکتی

## مرحله 1: دریافت پروژه

ابتدا سورس‌کد را از GitHub دانلود کنید.

می‌توانید از گزینه **Code → Download ZIP** استفاده کنید.

سپس فایل را استخراج کنید.

## مرحله 2: باز کردن پروژه

پوشه پروژه را در VS Code باز کنید.

## مرحله 3: نصب کتابخانه‌ها

ترمینال VS Code را باز کنید و دستور زیر را اجرا کنید:

```bash
npm install
```

منتظر بمانید تا وابستگی‌های پروژه نصب شوند.

## مرحله 4: اجرای فروشگاه

دستور زیر را اجرا کنید:

```bash
npm run dev
```

بعد از اجرای دستور، آدرس لوکال پروژه در ترمینال نمایش داده می‌شود.

معمولاً آدرسی مشابه زیر خواهد بود:

```text
http://localhost:5173
```

آدرس نمایش‌داده‌شده در ترمینال را در مرورگر باز کنید.

## مرحله 5: فعال‌سازی وب‌کم

در محیط فروشگاه، کنترل حرکتی را فعال کنید.

اگر مرورگر درخواست دسترسی به دوربین داد،
گزینه Allow را انتخاب کنید.

بعد از فعال شدن دوربین، می‌توانید
حرکات پشتیبانی‌شده را امتحان کنید.
